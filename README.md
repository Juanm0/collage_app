# Collage 30 fotos

Editor de collages en el navegador (HTML + CSS + JavaScript puro). Las fotos **nunca salen de tu dispositivo**.

## Uso
1. Elegí o arrastrá tus fotos (53, 100 o más). Podés agregar más después.
2. Tocá una foto (queda marcada) y tocá otra para intercambiarlas. También: arrastrá con el mouse, o mantené presionada una foto en el celular y movela.
3. Elegí Vertical u Horizontal, y "Nueva distribución" si querés otro mosaico.
4. Zoom con + / −, rueda del mouse o pellizco.
5. Elegí PNG o JPG, calidad y resolución, y tocá **DESCARGAR COLLAGE** (`collage-30-fotos.png` / `.jpg`).

La exportación vuelve a leer cada foto **original** (la vista previa usa miniaturas). La resolución final nunca inventa detalle que la foto no tenga. Si el equipo se queda sin memoria, la app te ofrece una versión más liviana.

## Ejecutar localmente
Descomprimí el ZIP y abrí `index.html` con Chrome, Edge o Brave (doble clic). No requiere instalación.

## Publicar en GitHub Pages
1. Creá un repositorio nuevo en github.com (por ejemplo `collage-30-fotos`).
2. Subí `index.html`, `styles.css`, `app.js` y `README.md` (Add file → Upload files).
3. En el repositorio: Settings → Pages → Source: "Deploy from a branch" → Branch `main` / carpeta `/ (root)` → Save.
4. En uno o dos minutos tendrás el enlace `https://TU-USUARIO.github.io/collage-30-fotos/`.
5. Compartí ese enlace: cada persona usa la app con sus propias fotos, que no se suben a ningún servidor.
